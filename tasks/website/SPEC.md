# MacTextify website

Build a polished public product website in `website/`. Preserve Pearl/Midnight identity and real product claims. Main actions: download a prepared preview and visit GitHub to read/contribute to the source.

## Acceptance
- Responsive home page explains PNG/JPEG → text/Markdown, on-device privacy and native macOS workflow.
- Distinctive, interruptible Anime.js screenshot-to-text demonstration with playback, scrub and copy controls. Clearly identified as a sample; no user files uploaded or processed.
- Adapt a reviewed Vengeance UI component with its MIT notice and provenance.
- Genuine native app imagery from synthetic fixtures, with useful alt text and no private content.
- Download section explains architecture, macOS requirements, unsigned/not-notarized preview status, checksum and installation. No fabricated release URL; source-only fallback when no prepared archive exists.
- GitHub source/contribution links work. All controls work with keyboard, touch and reduced motion; no horizontal overflow at 320, 390, 768, 1024 and 1440 px.
- Static build, TypeScript, meaningful browser checks, accessibility review, archive integrity and relevant app checks pass. Record untested downloaded-Gatekeeper behavior explicitly.

## Boundaries
No changes to the OCR implementation, private helper, study material or third-party dashboard fix. The user authorized review, fixes and a source commit/push on 27 October 2026. Scope publication to the website, its documentation, ignore rules and CI. Public site deployment and app binary publication remain separate actions. No disabling Gatekeeper. The prepared preview is local evidence, not a claim of a published production release.
